# OSAI example code for saving to and loading from data connection

1. open upload-these-files directory and look at what it contains
2. run 1_upload_to_s3.ipynb
3. delete upload-these-files directory
4. run 2_download_from_s3.ipynb - this creates data-connection directory
5. inspect data-connection directoy - comment on how its the same as upload-these-files
6. run 1_run_model_and_test.ipynb
